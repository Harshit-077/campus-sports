# Design exports

Put the screens generated in Google Stitch here, one folder per screen, numbered as in
`docs/DESIGN_BRIEF.md`:

```
design/stitch/
  01-landing/        screenshot.png  (+ the exported HTML/CSS or code, if your Stitch version offers it)
  04-student-dashboard/
  07-facility-slot-picker/
  ...
```

Mobile and desktop versions of the same screen go in the same folder (`desktop.png`, `mobile.png`).
These files are reference material for building the real components; they are not imported by the app.
